## 1. Vue d’Ensemble

Ce projet constitue la **plateforme web officielle et le portfolio professionnel** de Lola (Khaoula Kebbache). Il ne s'agit pas d'un simple blog ou agrégateur de liens, mais d'une identité numérique éditoriale de prestige conçue pour les marques de luxe, diffuseurs télévisuels, productions audiovisuelles, institutions et agences médias.

### Fonctionnalités Clés :
- **Homepage Éditoriale Haute Définition** : Hero immersif avec typographie serif épurée, disciplines majeures, mise en valeur audiovisuelle, mini-magazine beauté et galerie.
- **Multilingue Intégral** : Français (défaut), Arabe (avec prise en charge native du RTL, polices arabes calligraphiées et mise en page adaptée), et Anglais.
- **On Air (Télévision)** : Fiche complète de l'émission *Miss Fashion DZ* (animation prime time, format, rôles, galerie de plateau).
- **The Lola Beauty Edit** : Mini-magazine cosmétologique avec filtres interactifs (Skincare, Makeup, Coiffure, Parfumerie), temps de lecture et transparence des partenariats.
- **Portail de Collaboration Professionnelle** : Formulaire institutionnel complet avec protection anti-spam Honeypot, validation de types de projets, budgets prévisionnels et simulation de dépôt de briefs.
- **Media Kit & Salle de Presse** : Media kit dynamique exportable / imprimable en PDF haute fidélité, portraits officiels autorisés et formulaire presse dédié.
- **Espace Administrateur (CMS)** : Console de gestion protégée pour traiter les demandes de collaboration par statuts (NEW, REVIEWING, CONTACTED, etc.), éditer les biographies, actualiser les statistiques vérifiées et tracer les actions dans l'Audit Log.

## 2. Démarrage et Développement

```bash
# Installation des dépendances
npm install

# Démarrage du serveur local
npm run dev

# Validation TypeScript et linting
npm run lint

# Compilation pour la production
npm run build
```
